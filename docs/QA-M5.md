- [ ] **«ڈاؤن لوڈ»** دبائیں → progress bar چلے → مکمل ہونے پر بٹن **«حذف کریں»** بن جائے۔
- [ ] **«حذف کریں»** سے ماڈل ڈسک سے واقعی ہٹے۔

### 6.2 انجن کا انتخاب
- [ ] **«اردو صوتی انجن»** اور **«عربی صوتی انجن»** دونوں میں `Piper (آف لائن / مقامی)` اور `Edge TTS (آن لائن)` موجود ہوں۔
- [ ] **«ٹرانسکرپشن انجن»** میں `Whisper (آف لائن / مفت)` اور `کلاؤڈ (ٹوکن خرچ ہوں گے)` ہوں — یہ سیکشن **صرف ڈیسک ٹاپ** پر ہو۔
- [ ] Whisper منتخب کریں مگر کوئی ماڈل ڈاؤن لوڈ نہ ہو → سرخ انتباہ: *«کوئی Whisper ماڈل ڈاؤن لوڈ نہیں — نیچے ماڈل مینیجر سے ڈاؤن لوڈ کریں، ورنہ ٹرانسکرپشن کلاؤڈ سے ہوگی۔»*

### 6.3 ⚠️ `edge-tts` کا رضامندی گیٹ (FR-6.6)
- [ ] پہلی بار `Edge TTS (آن لائن)` منتخب کریں → ڈائلاگ **«آن لائن صوتی سروس کی اجازت (Microsoft Edge TTS)»** آئے، جس میں **Microsoft کا نام صراحتاً** ہو۔
- [ ] **«منسوخ (آف لائن رہیں)»** دبائیں → انجن **Piper پر ہی رہے** (بدلے نہیں) اور **کوئی network درخواست نہ جائے** (network monitor سے تصدیق)۔
- [ ] دوبارہ منتخب کر کے **«قبول ہے (آن لائن)»** دبائیں → تب انجن بدلے، اور تب ہی متن باہر جائے۔
- [ ] تیار آڈیو اور انجن مینو دونوں پر مستقل **«آن لائن»** بیج نظر آئے (FR-6.6/R22)۔
- [ ] **ناکامی کا ٹیسٹ:** endpoint بلاک کر کے Edge TTS چلائیں → **خودکار Piper پر واپسی + صاف پیغام**، خالی آڈیو نہیں (R21)۔

### 6.4 ⚠️ تقسیم شدہ ترکیب — فیصلہ کن امتحان (FR-6.5)
- [ ] اردو پیراگراف جس میں **«إنما الأعمال بالنيات»** ہو، اسے Speak پر چلائیں۔
- [ ] **متوقع:** عربی حصہ `ar_JO-kareem` میں، اردو حصہ `ur_PK` میں، اور **جوڑ ہموار** (بیچ میں جھٹکا یا خاموشی نہ ہو)۔

### 6.5 ٹرانسکرپشن اور سب ٹائٹل
- [ ] **60 منٹ کی اردو آڈیو** مکمل ٹرانسکرائب ہو، **کوئی ٹوکن نہ کٹے**، اور network **بالکل خاموش** رہے۔
- [ ] وہی فائل **عربی** میں → درست زبان کی شناخت۔
- [ ] `.srt` اور `.vtt` دونوں ایکسپورٹ ہوں → VLC میں کھول کر **وقت کی مطابقت** درست ہو۔
- [ ] بغیر timestamps والا انجن منتخب ہو تو پیغام آئے: *«اس انجن سے وقت کے نشانات نہیں ملے — سب ٹائٹل کے لیے Settings سے مقامی Whisper منتخب کریں۔»*
- [ ] نتیجہ صارف کو **«مسودہ»** کے طور پر پیش ہو، اور اردو WER کی حقیقت پہلے سے بتائی گئی ہو (FR-6.10/R24)۔

### 6.6 آڈیو بک (FR-6.9)
- [ ] ایڈیٹر میں عنوانات والی دستاویز کھول کر آڈیو بک ایکسپورٹ چلائیں۔
- [ ] پیش رفت نظر آئے؛ منسوخ کرنے پر toast: *«آڈیو بک ایکسپورٹ منسوخ ہو گئی۔»*
- [ ] مکمل ہونے پر toast: *«آڈیو بک تیار: N باب، تقریباً M منٹ»* اور `.mp3` **ابواب کے نشان (chapter marks)** کے ساتھ بنے۔
- [ ] بغیر عنوانات والی دستاویز → ایک ہی باب کی آڈیو بک بنے (انکار نہ ہو)۔

### 6.7 ویب ریگریشن
- [ ] **ویب** ورژن پر TTS/STT بعینہٖ پہلے جیسے چلیں — کوئی regression نہیں۔
