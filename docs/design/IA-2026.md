# EasyEditor 2026: نئی فیچر ترتیب (Information Architecture)

بنیاد: `docs/UIUX-AUDIT-2026.md` کا فیچر انوینٹری آڈٹ (کوڈ سے)۔ مقصد: تینوں پلیٹ فارمز (موبائل، ڈیسک ٹاپ، ویب) پر **ایک ہی نقشہ**، کم جگہیں، ہر کام کی ایک واضح جگہ۔

## 1. موجودہ مسائل (کوڈ سے ثابت)

| # | مسئلہ | اثر |
|---|---|---|
| 1 | دو الگ نیویگیشن شیل: `AppLayout` (سائیڈبار) اور Workspace (فیویکون ڈراپ ڈاؤن) | صارف کو معلوم نہیں ہوتا باقی ایپ کہاں ہے؛ ورک اسپیس میں نوٹیفکیشن اور ModeBadge غائب |
| 2 | موبائل نیچے کی نیویگیشن: ورک اسپیس، ٹرانسکرائب، سیٹنگز، ڈیش بورڈ؛ Speak، OCR، ترجمہ، پروفائل غائب | آدھے ٹولز تک رسائی مشکل |
| 3 | سلیکشن پر AI ایکشنز 5 جگہ (slash, bubble, toolbar، `MobileTaskSheet`، `SelectionActionBar`) | الجھن، غیر یکساں لیبل، مردہ UI |
| 4 | Workbench ٹیبز صرف آئیکن؛ اندر دوسرے ٹیب (Trust کے اندر Tasks!) | صارف کو فیچر ملتے ہی نہیں |
| 5 | تین "پرامپٹ لائبریریاں": Tasks، Custom prompts، Skills/Playbooks | ایک ہی تصور تین نام |
| 6 | سیٹنگز تین جگہ: `/settings`، ورک اسپیس ریل Settings، Profile؛ Graph اور Recipes "Settings" میں | چیزیں ڈھونڈنا ناممکن |
| 7 | پلان/استعمال/قیمت 8 جگہ دہرائے گئے؛ ادائیگی کا فلو دو بار لکھا گیا | عدم مطابقت، دوگنی دیکھ بھال |
| 8 | تلاش 6 جگہ بکھری | کون سی تلاش کہاں، معلوم نہیں |
| 9 | Export دو جگہ (ڈیسک ٹاپ مینو + موبائل مینو)، آڈیو بک الگ | |
| 10 | آواز کی سہولتیں تین جگہ (Speak، Voice، Advanced Voices)، Landing کی عبارت پروڈکٹ سے متضاد | |
| 11 | `/ocr` اور `/ocr/review` ایک ہی کام کے دو صفحے | |
| 12 | بگ: `/auth` پر 404، `window.prompt/confirm`، سخت کوڈڈ اردو | |

## 2. نیا نقشہ: 5 مقامات (سب پلیٹ فارمز پر وہی)

| مقام | کیا شامل | موبائل | ڈیسک ٹاپ/ویب |
|---|---|---|---|
| **لکھیں** | ایڈیٹر، Workbench (تحقیق، اعتماد، ٹاسکس، مطالعہ)، ایکسپورٹ | نیچے ٹیب | بائیں ریل |
| **مکتبہ** | دستاویزات، ذرائع (ذاتی کارپس)، شاملہ (براؤز/تلاش/پسندیدہ)، بصیرت (گراف، ریسیپیز) | نیچے ٹیب | بائیں ریل |
| **تحقیق** | ایجنٹ (Ask / Plan / Auto)، کنورسیشنز، آرٹیفیکٹس | نیچے ٹیب | بائیں ریل + Workbench |
| **ٹولز** | ٹرانسکرائب، آواز اسٹوڈیو (Speak + کلوننگ + انجن)، OCR (ایک ہی فلو)، کتاب کا ترجمہ | نیچے ٹیب | بائیں ریل |
| **میں** | پروفائل، پلان اور استعمال، ادائیگیاں، ریفرل، نوٹیفکیشنز، ترتیبات | نیچے ٹیب | ریل کے نیچے اوتار |

ایک ہی شیل: `AppLayout` اور Workspace کا فرق ختم۔ ریل/ٹیب بار ہر صفحے پر موجود؛ ورک اسپیس کے اندر بھی نوٹیفکیشن اور اکاؤنٹ اوتار۔ ڈیش بورڈ الگ صفحہ نہیں رہتا بلکہ **"لکھیں" کا ہوم** بن جاتا ہے (جاری کام، حالیہ، ٹول شارٹ کٹس، استعمال)۔

## 3. فیچرز کی منتقلی اور انضمام

1. **AI ٹاسکس کی ایک سطح:** ایک رجسٹری، تین سطحیں: سلیکشن بار (ڈیسک ٹاپ bubble / موبائل sheet)، slash `/`، کمانڈ پیلیٹ۔ ٹول بار کا AI گروپ، `SelectionActionBar` اور الگ لیبلز ختم۔
2. **ٹاسک لائبریری (ایک تصور):** Tasks + Custom prompts + Skills/Playbooks ایک ٹیب "ٹاسکس" میں، تین حصے: میرے، بلٹ ان، پلے بکس۔ Trust سے الگ۔
3. **Workbench ٹیبز (متن کے ساتھ، 4):** تحقیق · اعتماد · ٹاسکس · مطالعہ۔ ہر ایک کے اندر دوسرا ٹیب نہیں، سادہ سیگمنٹ صرف مطالعہ میں (کتاب/نوٹس)۔
4. **ایک تلاش:** Ctrl+K / موبائل پر مکتبہ کے اوپر سرچ بار؛ دائرے کے چپس: سب · دستاویزات · میرے ذرائع · شاملہ · تفسیر/حدیث۔
5. **ایک "شیئر/ایکسپورٹ" شیٹ:** Word، PDF، HTML، TXT، "Word کے ذریعے (اعلیٰ معیار)"، آڈیو بک، شیئر کارڈ۔ ڈیسک ٹاپ اور موبائل پر وہی۔
6. **ترتیبات ایک جگہ، ہر سیکشن کا اپنا URL:** عمومی · اکاؤنٹ اور پلان · AI اور کلیدیں (API) · آواز · کنیکٹرز (شاملہ، تفسیر، حدیث) · شارٹ کٹس · ایپ کے بارے میں۔ Graph اور Recipes مکتبہ کے "بصیرت" ٹیب میں۔
7. **اکاؤنٹ اور بلنگ:** Profile + Pricing + `PendingApproval` کی ادائیگی + Upgrade ڈائیلاگ ایک مشترکہ ادائیگی کمپوننٹ؛ پلان کارڈ ایک ہی جگہ "میں ← پلان"۔
8. **آواز اسٹوڈیو:** Speak، انجن (Piper/Edge)، کلوننگ ایک صفحے کے تین ٹیب۔ ڈیسک ٹاپ پر مقامی، ویب/موبائل پر کلاؤڈ، UI وہی۔ Landing کی کلوننگ والی عبارت درست۔
9. **OCR ایک فلو:** اپ لوڈ ← صفحہ وار جائزہ ← محفوظ۔ الگ `/ocr/review` ختم۔
10. **مکتبہ کے ٹیب ہمیشہ نظر آئیں:** شاملہ ٹیب بغیر کنکشن کے بھی ہو، اندر "جوڑیں" کی واضح اسکرین (موبائل پر لوکل کے بغیر: صرف کلاؤڈ)۔
11. **ڈیسک ٹاپ فائلز:** "فائلیں" مکتبہ کا ذیلی حصہ (پروجیکٹ فولڈر)، صرف ڈیسک ٹاپ پر۔ ویب پر آئیکن نہیں۔
12. **ماحول کا اشارہ:** ہر پلیٹ فارم پر ایک جیسا اسٹیٹس چپ (مقامی / کلاؤڈ / آف لائن / ہم آہنگی)۔

## 4. پلیٹ فارم فرق (آپ کے طے کردہ، بدلا نہیں)
سائن ان: ڈیسک ٹاپ پر اختیاری۔ اپنی API + endpoint: ڈیسک ٹاپ کو اضافی (ویب پر پینل رہے گا)۔ لوکل شاملہ: موبائل پر نہیں۔ OCR/ترجمہ/کلوننگ ڈیسک ٹاپ پر "فعال کریں" حالت کے ساتھ۔
