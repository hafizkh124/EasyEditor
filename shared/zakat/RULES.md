## 1. شرحِ زکوٰۃ — `ZAKAT_RATE = 0.025`

<a id="rate"></a>
مالِ نامی (نقدین، مالِ تجارت) میں **ربع العشر = ۲.۵٪**۔
دلیل: «…وَفِي الرِّقَةِ رُبْعُ الْعُشْرِ» (بخاري)، اور اجماع۔

## 2. نصاب — `NISAB`

<a id="nisab"></a>
| دھات | وزن | حوالہ |
|---|---|---|
| سونا | **۸۵ گرام** (۷.۵ تولہ / ۲۰ مثقال) | متفق علیہ |
| چاندی | **۶۱۲.۳۶ گرام** (۵۲.۵ تولہ) | حنفی موقف؛ بعض معاصر ادارے ۵۹۵ گرام (۷۰۰ مثقال) لیتے ہیں — `silverNisabGrams` سے قابلِ تبدیل |

- `standard: 'silver'` (ڈیفالٹ سفارش) — فقراء کے حق میں احتیاط۔
- `standard: 'gold'` — صرف سونے کا نصاب۔
- `standard: 'lower'` — `min(سونا، چاندی)`، عملاً چاندی۔

## 3. حول

<a id="hawl"></a>
مالِ زکوٰۃ پر **پورا قمری سال** (۳۵۴ دن) گزرنا شرط۔ انجن اِسے ایک بولین
(`hawlMet`) کے طور پر لیتا ہے — تاریخ کا حساب صارف/مفتی کرے۔ حول پورا نہ ہو تو
اُس مال کا `zakatable` صفر۔

## 4. سونا و چاندی — `computeMetalZakat`

<a id="gold-silver"></a>
- ہر holding: `{ grams, purity?, use? }`۔ قیمت **فی گرام خالص (24K)** لی جاتی ہے؛
  کم carat کے لیے `GOLD_PURITY` سے تناسب (`22K = 0.9167`, `21K = 0.875`, `18K = 0.75`)۔
- `use`:
  - `regular` — روزمرہ زیرِ استعمال
  - `occasional` — کبھی کبھار / تقریبات کے لیے
  - `investment` — بطور سرمایہ
- **`jewelleryRuling`:**
  - `'personal-exempt'` (ڈیفالٹ) — `regular` معاف، باقی قابلِ زکوٰۃ۔
  - `'hanafi-all'` — **سب** قابلِ زکوٰۃ (حنفی: ہر سونا چاندی، بشمول زیرِ استعمال زیور)۔

> **نوٹ برائے مفتی:** اصل `islamic-calculator` کا کوڈ `regular` کو hard-coded
> معاف کرتا تھا حالانکہ اُسی پروجیکٹ کا FAQ حنفی (سب قابلِ زکوٰۃ) کہتا ہے۔ M12
> میں یہ تضاد `jewelleryRuling` پیرامیٹر سے حل کیا گیا — دونوں مواقف دستیاب،
> نتیجہ ہر بار بتاتا ہے کون سا لگا۔

## 5. دیگر قابلِ زکوٰۃ اموال — `#zakatable-assets`

<a id="zakatable-assets"></a>
| مد | حکم |
|---|---|
| نقد و بینک | نقدین — پورا قابلِ زکوٰۃ (حول پر) |
| مالِ تجارت | قیمتِ بازار پر |
| سرمایہ کاری | برائے فروخت شیئرز پوری قیمت؛ طویل مدتی کا قابلِ زکوٰۃ حصہ صارف دے |
| واجب الوصول قرض | قرضِ قوی پر زکوٰۃ |
| خالص کرایہ آمدنی | (آمدنی − اخراجات)، ≥ 0 |
| برائے فروخت جائیداد | عروضِ تجارت کے حکم میں |
| خالی زمین | غیر مستعمل، برائے نفع — قابلِ زکوٰۃ |
| **بنیادی رہائش، ذاتی استعمال کی اشیاء** | **معاف** (انجن اِنہیں input ہی نہیں لیتا) |

## 6. واجبات (منہا) — `#liabilities`

<a id="liabilities"></a>
- `debtsDue` — فوری واجب الادا قرض: پورا منہا۔
- `longTermDebtAnnual` — طویل مدتی قرض: صرف **ایک سال کی قسط** منہا، کل اصل نہیں۔
- `netBase = max(0, Σ قابلِ زکوٰۃ اموال − Σ واجبات)`۔
- نتیجہ اضافی حفاظت: `min(netBase, کل قیمت)` (منفی نہیں ہو سکتا)۔

## 7. نصاب سے موازنہ

`nisabMet = netZakatableBase ≥ nisabThreshold`۔
`zakatDue = nisabMet ? netZakatableBase × 0.025 : 0`۔

## 8. فدیہ / کفارہ / صدقۃ الفطر — `charity.ts`

<a id="charity"></a>

### صدقۃ الفطر — `sadqaFitr`
- ہر فرد پر **ایک صاع** (بخاري: ۱۵۰۳، ۱۵۰۶؛ اجماع — الإجماع لابن المنذر)۔
- احتیاطاً **۲.۵ کلو گندم** فی صاع (اہل علم کے بیان کردہ اوسط ۲.۱–۲.۵ کلو میں سے زیادہ)۔
- قیمت کی ادائیگی جائز — **لجنۃ العلماء للإفتاء، فتویٰ نمبر ۲۹۰**۔

### فدیہ — `fidya`
- عاجزِ دائمی پر ہر روزے کے بدلے ایک مسکین کا کھانا (البقرہ: ۱۸۴)۔
- **نصف صاع = ۱.۲۵ کلو گندم** فی روزہ۔
- **قضا کی طاقت رکھنے والے پر قضا لازم ہے، فدیہ نہیں۔**

### کفارۃ الیمین — `kaffaraOath`
- **دس مساکین** کو کھانا یا کپڑے (فی قسم)، یا غلام آزاد کرنا؛ اِن پر قادر نہ ہو تو تین دن روزے (المائدہ: ۸۹)۔
- انجن صرف کھانا/کپڑے کی مالی قیمت دیتا ہے۔ روزے کا اختیار = مالی قیمت صفر۔
- **صرف قسم کا کفارہ** — روزہ توڑنے (۶۰ مساکین / ۶۰ روزے)، ظہار، قتل کا کفارہ اِس میں نہیں۔
