# Contributing to Al-Ulama Easy Editor

First off, thank you for considering contributing to Al-Ulama Easy Editor!

## Code of Conduct
This project and everyone participating in it is governed by our open source standards. Please treat all contributors with respect.

## How Can I Contribute?

### Reporting Bugs
Bugs are tracked as GitHub issues. When creating a bug report, please include:
- A clear, descriptive title
- Steps to reproduce the issue
- Expected vs actual behavior
- Electron Desktop version or Browser version

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Ensure code passes all quality gates:
   - `npm run typecheck`
   - `npm run test`
   - `npm run lint`
   - `npm run build`
3. Maintain exact RTL, Arabic, and Urdu formatting standards.
4. Open a Pull Request with a comprehensive description of your changes.
